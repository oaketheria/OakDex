# FireRed battle animation extraction

Local workspace for studying/capturing move animations from `fire-red.gba`.

## Confirmed ROM

- Title: `POKEMON FIRE`
- Game code: `BPRE`
- Size: `16777216`
- SHA1: `00B403124A9C473142837DD074DACD3EB1B945DB`

## Capture workflow

1. Open `fire-red.gba` in mGBA.
2. Reach a battle where the desired move can be used.
3. In mGBA, use the built-in recording/screenshot tools to capture the move animation.
4. Save raw captures under `assets/battle-animations/raw/`.
5. Save edited GIFs or spritesheets under `assets/battle-animations/processed/`.

Keep extracted/captured assets local unless you have the rights to distribute them.
